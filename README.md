# 🚀 1-Month Web Development Training & Internship Repository

Welcome to my 1-Month Web Development Training repository! This repository tracks my daily learning progress, practical code exercises, project implementations, and weekly presentation materials.

---

## 🗓️ Weekly Training Schedule

* **Monday**: 🎤 Presentation & Live Project Demo Day
* **Tuesday – Sunday**: Intensive Learning, Hands-on Coding & Project Building

---

## 🗺️ Curriculum Roadmap

### 📌 [Week 1: Web Foundations, Git & Advanced JavaScript](./Week-1-Web-Foundations-and-JS/)
- **Topics**: HTML5 Semantics, Modern Web Design, Tailwind CSS, Git/GitHub Team Workflows, JavaScript Core & ES6+.
- **Deliverable**: Responsive Async Web Component & JS Practice Snippets.
- **Monday Presentation #1**: *Modern JavaScript & Web Design Standards*

### 📌 [Week 2: React Deep Dive & Component Architecture](./Week-2-React-Deep-Dive/)
- **Topics**: JSX, Props, State, Interactivity, Effects vs Handlers, Escape Hatches (`useRef`).
- **Deliverable**: Interactive Tic-Tac-Toe App with Undo/Redo & Custom Features.
- **Monday Presentation #2**: *React Fundamentals & State Synchronization*

### 📌 [Week 3: Backend Development (Node.js, Express & MongoDB)](./Week-3-Node-Express-MongoDB/)
- **Topics**: Node.js Event Loop & FS, Express REST APIs, MongoDB CRUD, Aggregations, Indexes & Mongoose.
- **Deliverable**: Full RESTful CRUD API with Mongoose ODM & Validation.
- **Monday Presentation #3**: *Building Scalable Backends with Node.js & MongoDB*

### 📌 [Week 4: Full-Stack Integration with Next.js](./Week-4-NextJS-FullStack/)
- **Topics**: Next.js App Router, SSR vs SSG, Server Components, API Routes, Performance & SEO.
- **Deliverable**: Production-Ready Full-Stack Web Application.
- **Monday Presentation #4**: *Full-Stack Web Applications with Next.js*
