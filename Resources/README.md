## ⚛️ React & Frontend Architecture

React is a declarative, efficient, and flexible JavaScript library for building user interfaces.

### 📖 Official Documentation & Core Concepts
* **[Official React Documentation](https://react.dev/learn)** — Comprehensive guide for understanding and practicing fundamental principles.
* **[Thinking in React](https://react.dev/learn/thinking-in-react)** — *(Crucial Guide)* Step-by-step approach to breaking UI designs into component hierarchies and state structures.
* **[Describing the UI](https://react.dev/learn/describing-the-ui)** — JSX syntax, components, props, and conditional rendering.
* **[Adding Interactivity](https://react.dev/learn/adding-interactivity)** — Event handling, component state, snapshot updates, and queueing.
* **[Managing State](https://react.dev/learn/managing-state)** — Structuring state, sharing state between components, and reducer logic (`useReducer`).
* **[Escape Hatches](https://react.dev/learn/escape-hatches)** — Synchronizing with external systems using `useRef` and `useEffect`.

### 🧪 Practical Code Examples & Projects
* **[Interactive CodePen Example](https://codepen.io/Shamiul_Hoque/pen/LNavdZ)** — Live interactive demonstration of React component state and interactivity.
* **[Tic-Tac-Toe Tutorial Project](https://react.dev/learn/tutorial-tic-tac-toe)** — Hands-on tutorial covering state management, immutability, and time travel (undo/redo).

## 🌐 Full-Stack & SSR Frameworks (Next.js)

Next.js is a premier production React framework enabling hybrid rendering strategies, optimized routing, and SEO best practices.

### 📖 Next.js Resources
* **[Next.js Documentation](https://nextjs.org/docs)** — Complete API reference and feature highlights.
* **[Building Applications with App Router](https://nextjs.org/docs/app/building-your-application)** — Server Components, Client Components, Layouts, Pages, and API Routes.

### 💡 Core Architectural Concepts
- **Server-Side Rendering (SSR)**: Dynamic page generation on each HTTP request for real-time content delivery.
- **Static Site Generation (SSG)**: Pre-rendering HTML pages at build time for fast delivery via CDN.
- **Search Engine Optimization (SEO)**: Pre-rendered HTML allows web crawlers to index dynamic content seamlessly, improving search engine visibility and load speed.
