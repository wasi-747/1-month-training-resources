React Core & Immutability

Foundational Architecture Principles

⬇️ Uni-directional Flow

  • Props flow strictly down to children
  • Event callbacks bubble updates up
  • Single Source of Truth eliminates desync

🌳 Virtual DOM

  • In-memory lightweight JS tree representation
  • Reconciliation diffing checks changed nodes
  • Batched, minimal real DOM commits

🔒 State Immutability

  • O(1) Shallow Reference Check (prev !== next)
  • Spread operator [...prev] creates fresh pointers
  • Preserves isolated Time-Travel snapshots

Lifecycle & Custom Hooks Architecture

Managing Side Effects and Encapsulating Reusable Logic

🔄 useEffect Sync

  • Synchronizes with external systems (APIs, Listeners)
  • Controlled dependency arrays prevent infinite loops

🧹 Cleanup Phase

  • return () => { ... } runs on unmount / re-run
  • AbortController cancels active fetch requests
  • Removes window listeners to eliminate memory leaks

🧩 Custom Hooks

  • Decouples complex side effects from UI rendering
  • useFetch: Handles data, loading, error & auto abort
  • useToggle: Manages modal & boolean UI state cleanly

MongoDB, Mongoose & Next.js Foundations

Backend Document Storage & Modern Rendering Paradigms

🍃 MongoDB BSON

  • Binary JSON (TLV byte structure with Date, ObjectId)
  • Embedded Sub-docs eliminate expensive SQL JOINs
  • Fast aggregation pipelines in database memory

🛡️ Mongoose ODM

  • Strict Schema validation & enum constraints
  • Pre-save normalization middleware (auto tag trim)
  • Fallback mock engine for resilient offline execution

▲ Next.js Paradigm

  • Server Components: Direct DB query, 0 KB client JS
  • Client Components ('use client') for interactivity
  • Global singleton cached DB connection pool
