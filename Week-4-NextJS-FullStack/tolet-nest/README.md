# 🏡 ToLetNest — Hyperlocal Smart To-Let & Roommate Finder

> **"One Ecosystem, Two Apps"** — A Full-Stack MERN / Next.js Web Admin Portal & React Native Mobile Client designed to solve urban student and bachelor accommodation discovery with 100% financial transparency and privacy protection.

---

## 🚀 Key Features

### 1. 💰 Transparent Utility Pricing Engine
* **Base Rent + Itemized Utilities:** Eliminates hidden bill surprises by clearly breaking down electricity, gas, water, service charge, WiFi, and maid charges.
* **Instant Total Cost Badge:** `৳8,500 Base Rent + ৳1,450 Utilities = ৳9,950/mo Total Estimated Living Cost`.

### 2. 📍 1-Tap Nearby GPS Proximity Radar
* **Proximity Scan:** 1.5 km radius scan with animated radar pulse sweep.
* **Real-Time Distance Badges:** Shows exact proximity e.g. `📍 350m away from NSU Gate 2` or `📍 Saidnagar Main Road`.
* **Cross-Area Search:** Search and filter listings in Bashundhara, Saidnagar, Gulshan, Banani, Dhanmondi, and Mirpur.

### 3. 🔒 Privacy-First In-App Voice Calling & Anti-Harassment Shield
* **In-App WebRTC Calling Simulator:** Call landlords directly through the application audio stream without exposing personal SIM phone numbers.
* **One-Tap "Close Chat" Shield:** Tenants can close negotiations with 1 click if terms don't match, instantly blocking any unsolicited follow-ups.

### 4. 🌐 Landlord & Property Manager Web Dashboard
* **1-Minute Smart Listing Form:** Post new To-Lets with live card preview and itemized utility configurator.
* **Inquiry Inbox:** Manage student chats, status updates (`Available 🟢` ↔ `Rented 🔴`), and call logs.

---

## 🛠️ Tech Stack (Strict Curriculum Compliance)
* **Web Frontend & API:** React 18, Next.js 14 (App Router), Pure JavaScript (ES6+), Tailwind CSS & Lucide Icons.
* **Mobile Client:** Pure React Native Core components (`View`, `Text`, `FlatList`, `TouchableOpacity`, `Modal`, `StyleSheet`).
* **Database Layer:** MongoDB + Mongoose ODM (GeoJSON 2dsphere spatial index + cached singleton connection pool + in-memory reactive fallback).
