## 📌 Summary of Learnings

### 1. Modern Web Design & Layouts
- **Semantic HTML**: Using structural tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) for accessibility and clean DOM architecture.
- **CSS Flexbox vs Grid**:
  - Flexbox for 1D alignments (navbars, row stacks, centered elements).
  - CSS Grid for 2D complex layouts (cards, dashboards).
- **Tailwind CSS**: Utility-first CSS workflow for rapid, responsive design with standardized design tokens.

### 2. Git & GitHub Professional Workflows
- **Branching**: Keeping `main` stable while developing in feature branches (`git checkout -b feature/day-01-js-snippets`).
- **Commit Standards**: Writing meaningful commit messages (`feat: add ES6 array manipulation practice`).
- **Team Collaboration**: Managing work through GitHub Issues, Pull Requests, and clear documentation.

### 3. JavaScript Core Concepts & ES6+
- **Variables & Scope**:
  - `const`: Block-scoped, immutable identifier binding.
  - `let`: Block-scoped, re-assignable variable.
  - `var`: Function-scoped, hoisted (avoid in modern JS).
- **Functions**: Declarations vs Expressions vs Arrow functions (`const add = (a, b) => a + b`).
- **Modern Syntax**: Destructuring assignment, Rest/Spread operators (`...`), and Template Literals (`${var}`).
- **Array Iteration**: Using `map()`, `filter()`, and `reduce()` for functional data transformations.
